## The complete ladder — HARBOE (actual 4,778,907 units)

| Scenario | mean forecast | median APE | CV across repeats | latency | cost (3 runs) |
|----------|--------------:|-----------:|------------------:|--------:|--------------:|
| **A** plain LLM | 3,166,667 | 35.1% | 3.65% | 108.7 s | $1.482 |
| **B** data + code | 3,833,333 | 17.3% | 5.27% | 115.4 s | $0.830 |
| **C** trained model | 4,117,982 | **13.8%** | **0.00%** | **5.9 s** | **$0.020** |

**Both increments are positive, which is what the three-scenario design exists to
separate:**

- **A → B (data access): +17.8pp.** Giving the agent the firm's own history halves
  the error. This is the larger increment, and it is the one a two-scenario design
  would have conflated with the next.
- **B → C (model integration): +3.5pp.** Exposing a *trained model* on top of that
  data adds a further improvement. This increment is the thesis contribution.

The second increment is smaller than the first. Say so plainly — the honest
reading is that most of the value comes from data access, and model integration
adds a real but secondary accuracy gain **whose case rests on consistency, cost
and latency rather than on accuracy alone.**

## B vs C, both brands (6 runs each)

| Brand | Scenario | rep 0 | rep 1 | rep 2 | APE |
|-------|----------|------:|------:|------:|-----|
| COCA COLA | B | 3,427,000 | 3,448,467 | 3,459,436 | 8.7 / 9.4 / 9.7% |
| COCA COLA | **C** | **3,105,464** | **3,105,464** | **3,105,464** | **1.5% x3** |
| HARBOE | B | 3,600,000 | 3,950,000 | 3,950,000 | 24.7 / 17.3 / 17.3% |
| HARBOE | **C** | **4,117,982** | **4,117,982** | **4,117,982** | **13.8% x3** |

C wins on **every single run of both brands**. C's worst run beats B's best run
on both. Aggregate: median APE 7.7% (C) against 13.5% (B).

### Consistency

C returned the identical number 6 times out of 6. B produced three distinct
values for Coca Cola and two for HARBOE. On HARBOE, **B's spread
(3.60M–3.95M) is wider than C's entire error.**

This is a property of a deterministic model, not a statistical estimate — one
run demonstrates it, and no confidence interval is needed.

### Cost and where it goes

| | input tokens | output tokens | reasoning tokens |
|---|---:|---:|---:|
| B | 11,774 | 5,917 | 5,634 (**95% of output**) |
| C | 578 | 129 | 20 (16%) |

**C is 39x cheaper and 22x faster.** B spends 95% of its output tokens thinking:
writing code, backtesting, comparing models. It is paying to re-derive a
forecasting method on every single query.

### B is not a straw man

Across the six runs B ran **9–16 code blocks each**, ensembling seasonal-naive,
month-of-year averages and log-trend regressions with expanding-window
backtesting. It is doing serious work. C beats a genuine effort, not a naive one.

### A shared limitation, not a C advantage

Both B and C under-forecast HARBOE (B −19.8%, C −13.8%) while diverging on
Coca Cola (B +9.3%, C −1.5%). Both missing the same brand in the same direction
suggests a genuine January uplift that neither could see from history. Report it
as a shared limitation rather than crediting C.

## The defect this run caught

The first run asked *"What will {brand} sell …?"*. **All six Scenario A runs
answered in DKK** — 145,000,000 DKK for Coca Cola against a 3,152,932 unit
actual, scored as a 4500% error.

The model was not hallucinating: ~145M DKK for monthly Danish Coca-Cola CSD
retail is a plausible *value*. It answered the question asked.

Scenarios B and C were immune because they infer the unit from the data handed
to them. Scenario A has no data, so the ambiguity hit exactly one scenario,
making its measured accuracy an artefact of prompt wording — precisely the
confound the shared question exists to remove.

**Fixed** to *"How many units of {brand} will be sold …? Answer in units sold,
not currency."* Re-run confirms it: all three runs answered in units, and the
error fell from 570% to 35.1%.

## What can and cannot be claimed

**Can be claimed now:**

- Scenario C is deterministic across repeats; B is not. (A property, n-independent.)
- C costs ~39x less and responds ~22x faster, on measured tokens and wall-clock.
- Both ladder increments are positive on HARBOE.

**Cannot be claimed yet:**

- A confidence interval on the accuracy gap. n=6 per scenario, 2 brands, 1
  category. F17 sizes this: n=10 gives a ±1.9% CI on B's mean and detects a
  2.65% gap at 80% power.
- Coca Cola's Scenario A figure — the budget cap stopped the re-run first.
- Anything about danskvand, energidrikke or RTD.

**The defensible headline** is the three-way asymmetry, not accuracy alone:

> Exposing a trained model as a tool produced identical answers across repeated
> queries, at 1/39th the cost and 1/22nd the latency, while matching or exceeding
> the accuracy of an agent that wrote its own forecasting code. The code-writing
> agent varied by up to 9% across identical queries and spent 95% of its output
> tokens re-deriving a method it had already used.

That survives B occasionally winning on accuracy at larger n, because
consistency, cost and latency are structural rather than statistical.
