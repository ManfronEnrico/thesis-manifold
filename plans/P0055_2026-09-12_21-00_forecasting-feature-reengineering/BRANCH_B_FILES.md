## The announcement rule — the part that is easy to skip

A regenerated table that silently contradicts a sentence already written is the
failure mode here. It is the same class as the `summary.md` defect found on
2026-09-12, where a figure was true when typed and wrong after the next run.

**After regenerating anything under `05_thesis_results/`, append to
`progress.md`:** which table, which numbers moved, and which chapter cites it.
The other session can then check whether a number it has already quoted has
changed underneath it.

Tables most likely to be cited by a chapter being written right now:

| Table | Cited by | Changes if |
|---|---|---|
| `09_statistical_baselines.md` | Ch5, Ch9 limitations | tasks 2, 8 |
| `mase.md` | Ch5, Ch9 limitations | tasks 2, 7 |
| `cv_metrics.csv`, `calibration.md` | Ch5, Ch7 | task 10 retrain |
