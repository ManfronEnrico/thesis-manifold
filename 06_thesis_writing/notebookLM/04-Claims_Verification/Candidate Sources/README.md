## Rule

**A document here is a candidate, not yet a source.** It becomes a source only once it
has been opened and confirmed to contain the claim - at which point it goes into Zotero
and the register row is updated.

A file sitting in this folder proves only that it was downloaded. That distinction is
the entire reason this verification folder exists.
